# ✦ SONIA Events & Experiences

A modern, elegant, and responsive **Event Management Website** designed for **SONIA Events & Experiences**.

The website provides an attractive digital presence for an event management team, showcasing their services, events, gallery, team members, reviews, and contact information.

## 🌟 Features

* 🏠 Modern and responsive Home page
* 👩‍💼 About Us and Team section
* 🎉 Event management services
* 📅 Events and celebrations showcase
* 🖼️ Interactive Gallery
* 📝 Blog section
* ⭐ Reviews and Feedback section
* 📞 Contact section
* 📱 Responsive design for different screen sizes
* ✨ Smooth animations and hover effects
* 🔗 Social media links
* 🎨 Professional pastel/glassmorphism-inspired UI

## 📄 Website Pages

1. **Home** – Introduction and highlights
2. **About** – Information about SONIA Events & Experiences and the team
3. **Services** – Event planning and management services
4. **Events** – Featured and upcoming events
5. **Gallery** – Collection of event photographs
6. **Blog** – Event-related articles and updates
7. **Contact** – Contact details and enquiry section

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in **Visual Studio Code**.
3. Open `index.html`.
4. Right-click and select **Open with Live Server**
   *(or simply open `index.html` in a web browser).*
